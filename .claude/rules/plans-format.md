# 계획서 형식

## 문서 묶음

```
00-INDEX.md               매트릭스, 문서 맵, Phase 게이트, 의존성 사슬, §8 정합성, §8.4 결정 대장
01~08-<slug>.md           작업 1~8 기술 명세서. 날짜 순
09-p1-roadmap.md          심사 이후 P1. 날짜 없음
10-backend-contract.md    백엔드 필독 계약서. §14 미결, §15 날짜별 결정 기록
```

- 문서 번호가 곧 참조 ID다. 인용은 `10 §15.2`, `01 CT-07`, `08 §3.4`처럼 번호와 절, 카드만. 파일명은 링크할 때만
- 근거 문서 proposal2와 기획서는 git에 없다. 새 절을 쓸 때 "proposal2 §N 참고"로 끝내지 말고 계약, DDL, 수치를 옮겨 적는다

## 골격(01~09 공통)

```
# 🛠️ [Tech Spec] 기술 명세서: 작업 N — 주제 · 주제 (마감 날짜 또는 M2 9/10)

> 근거: proposal2 §a, §b …, §20 작업 N + 먼저 실패시킬 케이스(케이스 1 · 케이스 2).
> **선행 문서: 01·02.** 백엔드 몫은 `10-backend-contract.md` §n. 이 문서는 **우리 쪽**만 다룬다.
> 한 줄 요약 또는 완료 기준: **굵게 핵심 조건**.

## 1. 개요 및 구현 목표
### 목적:  ### 핵심 플로우:  ### 현상태
## 2. 작업 범위 (Scope Boundary)
### In-Scope (| # | 항목 | 등급 | 난이도 |. #은 3.x 절 번호와 일치)
### Out-of-Scope ("→ 작업 N"으로 소속 명시)
### 다른 파트에 요청 (| 대상 | 요청 | 기한 |)
### 팀 결정 대기
## 3. 기술 상세 설계 (Technical Design)
### 3.x 제목 (`구현/파일/경로.py`, proposal2 §n)
## 4. 완료 기준 (DoD)
### 4.1 정량 목표 (| 지표 | 목표 | 측정 |. 측정 열은 테스트 파일명)
### 4.2 검증 테스트 시나리오 (테스트 파일별 `- [ ]`)
### 4.3 동작 확인 가이드 (수동) (bash 블록, `uv run …`)
### 최종 완료 기준 (`- [ ]`. 확정은 `- [x]` + "— 9/8 확정")
## 5. 작업 분할 (Task Breakdown — 카드 연동)
```

- 등급 `Critical/High/Medium/Low`, 난이도 `S(≤ 0.5일)/M(1~2일)/L(3일+)`, 카드 예상 `0.25d/0.5d/1d`
- §5 카드 표 열은 `| # | 카드명 | 설명 | 라벨 | 예상 | 선행 |`. 카드 ID는 문서별 접두어 + 2자리. 표 아래에 `**CT-02** — [ ] 항목 / [ ] 항목`
- 10 계약서는 예외다. `## 0. 읽는 법` 표 → 절별 계약 → `§13 수용 검사` → `§14 미결(| ID | 항목 | 기한 |)` → `§15 날짜별 결정 기록`
- 표기 습관. 숫자와 단위 사이 공백 없음(`7~8초`, `0.5d`), 한글과 코드 사이 한 칸, 강조는 `**…**`, 이모지는 제목에만

## 결정 대장 갱신 절차

1. 결정은 두 곳에 기록한다. `10 §15`의 날짜별 표(`| ID | 결정 | 백엔드가 할 일 | AI 파트가 할 일 |`)와 `00 §8.4` 체크리스트. 백엔드 무관한 AI 내부 결정은 `10 §15.3`
2. 미결을 확정으로 바꿀 때 원문을 지우지 않는다. `~~D-20~~ **9/8 확정(10 §15.2)** — 남은 것: …`. 체크리스트는 `- [x] **D-20** — 9/8 확정: 내용(참조)`. 예전 문장을 남길 때는 `(원문)` 접두
3. 그 결정 ID나 enum을 인용한 문서를 전부 grep해 같은 커밋에서 고친다. 갱신 뒤 "결정했는데 아직 미결로 남은 문장"이 없는지 한 번 더 훑는다
4. 완료된 카드 항목은 `~~…~~(9/8 완료 — 내용)`. 부분 완료도 같다
5. 실측 뒤 채울 결정은 빈칸으로 둔다. `sentencing p90 ____초 → 유지 / 후보`. 임의 값으로 채우지 않는다
6. 백엔드에 제안하는 항목에는 `(제안)`을 붙이고 `10 §14` 미결 표에 기한과 함께 올린다
7. 수치를 바꾸면 `00 §1` 표와 `§7` 표도 같이 바꾼다
