# 사유에 맞는 판결문·세 강도 문체 개선

**Goal:** 사용자가 제공한 5개 사례의 말투를 반영하되, 입력에 없는 사실로 비난하지 않는다.

**Architecture:** 기존 조서·드립·양형·서기·검수 호출을 유지한다. 서기는 근거가 있는 기법 중
사유와 평결에 맞는 것을 선택한다. 원문 사유를 우선하고 모델 추론은 사실과 구분한다.
서기와 드립에 동일한 강도별 예시를 제공하며 검수도 같은 기준을 사용한다.
외부 계약·DB·모델 기본값은 변경하지 않는다. 새 의존성·모델 호출 단계는 추가하지 않는다.

**Tech Stack:** Python 3.12, Pydantic, LangGraph, pytest, Ruff.

## 승인된 문체

- 순한맛: 존댓말로 구체적으로 지적. 무조건 위로하지 않으며 짧은 당부·훈계 가능.
- 매운맛: 반말·채팅체로 모순을 약 올림. 도랏나·ㅇㅈㄹ 같은 가벼운 거친 표현 가능.
- 지옥맛: 어이없다는 반응·되묻기·면박. 욕은 선택이며 욕을 지워도 태도가 구분되어야 한다.
- 승인·무죄도 퉁명스러운 말투는 가능하나 필요성을 뒤집거나 사치·과소비를 만들어내지 않는다.
- 죽음·정체성 비하 제한 유지. 소득·가격 비교·반복·실행 가능한 대안은 근거 없이 단정하지 않는다.
- 제목 20자·본문 100자·본문 배열 1개 유지. 감탄·문장 조각 개수는 제한하지 않는다.

## 검증 기준

- 정상: 같은 사실에 세 강도, 사유 원문이 긴 경우에도 보존, 자연스러운 채팅 문장.
- 경계: 첫 지출에 반복 생성 금지, 승인·무죄 필요성 인정, 사유 없는 경우 추측 금지.
- 실패: 금지 기법 출력·길이 초과·검수 실패는 기존 재작성/폴백으로 처리.
- 평가: 같은 품목에 늦잠/막차 종료 등 사유를 바꿨을 때 다른 반응. 소득·단위 오류 없음.
- 운영: 기존 호출 상한·타임아웃·캐시 번들 해시·공개 범위 유지. 새 모델 비교 시
  동일 사례의 품질과 비용·지연·폴백률을 함께 기록한다.

## 모델 비교와 운영 유의점

- 모델을 변경하지 않았다. `MODEL_WRITER`는 드립·서기, `MODEL_JUDGMENT`는 양형·검수다.
  현재 서기 라우팅은 xAI이므로 다른 제공자 모델 이름만 넣으면 전환되는 구조가 아니다.
  후보 모델의 제공자·구조화 출력·가격·타임아웃을 확인한 뒤 같은 사례로 비교한다.
- 새 모델 호출 단계는 없지만 서기의 내부 `case_reading`과 예시로 토큰 사용량이 달라진다.
  `case_reading`은 공개 판결 계약이나 사실 근거에 넣지 않고, 검수는 원문 사유를 사용한다.
- 길이 초과를 잘라 구제하지 않으므로 기존 1회 재작성이 더 자주 발생할 수 있다.
  실제 운영에서는 길이 실패율·재작성률·타임아웃을 함께 확인한다.
- 백엔드 호환을 위해 정책 이름은 `guardrail-v2`를 유지하고 검수 프롬프트 파일을
  현재 `guardrail-v2.2.md`로 버전 관리한다. 프롬프트 번들 해시가 바뀌므로 옛 준비 자료는 재사용되지 않는다.
- 커밋·푸시·배포는 하지 않았다.

## 지옥맛 추가 참고 예시 (사용자 제공, 2026-09-20)

상황: 마라톤 후 마라탕을 먹은 소비에 친구가 단 댓글. 사용자는 아래 원문을
**지옥맛에 적합한 예시**로 지정했으며, 나중에 참고하도록 제공했다.

> 먼 마라탕 ㅇㅈㄹ 마라탕 쳐먹을 시간에 더 뛰어. 뛴 칼로리 <<< 마라탕 칼로리 ㅋㅋㅋㅋㅋ 그냥 쳐먹지도 말고 뛰지도 마 쌰갈

말투에서 참고할 점:

- 사유의 구체적인 소재(마라톤·마라탕)를 바로 물고 늘어지며 반응한다.
- 거친 반말·비속어·비교 기호·긴 웃음을 섞고, 마지막까지 친절한 조언으로 순화하지 않는다.
- 지옥맛의 거친 친구 댓글 말투를 보여준다. 비속어뿐 아니라 집요한 비꼼과 끝까지 몰아붙이는 태도를 참고한다.
- 마지막의 과격하고 모순된 명령은 댓글의 농담·호흡을 보여주는 예시이며 실제 행동 지침은 아니다.
- 거리·섭취량 등은 제공되지 않았다. 칼로리 부등식은 원문의 과장이며 확인된 사실로 재사용하지 않는다.

현재는 참고 기록만 추가했다. 운영 v6.2의 프롬프트·어휘 필터·검수 기준은 이번 기록으로 바뀌지 않는다.
향후 지옥맛 예시를 보강할 때 참고한다. 매운맛의 기존 기준을 높이는 근거로 사용하지 않는다.
